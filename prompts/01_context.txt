Контекст проекта YaDiskDownloader
===================================

Путь: d:\Projects\YaDiskDownloader\
Язык: Python 3.12
Зависимости: aiohttp, pyyaml
ОС: Windows 10/11 (cmd.exe)

Структура:
- config.yaml — токен, путь скачивания, настройки
- config.example.yaml — шаблон конфига
- src/main.py — основной скрипт
- logs/ — логи скачивания
- .venv/ — виртуальное окружение

Что делает скрипт:
1. Читает OAuth-токен из config.yaml
2. Сканирует Яндекс.Диск по API (BFS обход папок)
3. Для каждого файла получает pre-signed URL
4. Скачивает файл по URL без заголовка Authorization (URL уже подписан)

API Яндекс.Диска:
- GET /v1/disk/resources?path=... — список файлов в папке
- GET /v1/disk/resources/download?path=... — получение ссылки на скачивание
- Ссылка на скачивание (href) — pre-signed, действует ограниченное время

Известно:
- На диске 21+ папка в корне, много вложенных
- Есть файлы до 847 МБ (видео)
- Пути содержат кириллицу и спецсимволы
