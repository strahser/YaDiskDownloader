Ожидаемый результат
===================

1. Исправленный main.py, который:
   - Корректно обрабатывает пути с кириллицей и URL-символами
   - Имеет retry с экспоненциальной паузой для всех сетевых операций
   - Докачивает частично скачанные файлы (или начинает заново)
   - Имеет пагинацию для папок с более чем 1000 файлов
   - Показывает прогресс (tqdm или аналог)
   - Проверяет свободное место на диске
   - Пишет логи в UTF-8
   - Не роняет весь процесс при ошибке одного файла
   - Делает финальный проход по неудачным файлам

2. Обновлённый requirements.txt (если нужны новые зависимости)

3. Краткая инструкция по запуску и тестированию

4. Список изменений (что было → стало)

Критерии приёмки:
- Скрипт запускается и скачивает без зависаний
- Пути с кириллицей обрабатываются корректно
- При обрыве сети файл докачивается, а не пропускается
- Виден прогресс скачивания
- Логи читаемы (UTF-8)
