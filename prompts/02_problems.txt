Найденные проблемы в коде
=========================

1. yd_to_local() — некорректная обработка путей
   - Использует простой replace("disk:/", "")
   - Не декодирует URL-символы (пробелы, кириллица в пути)
   - На Windows пути с кириллицей могут ломаться

2. Нет retry для download_file()
   - list_dir имеет retry (2 попытки)
   - download_file — одна попытка, при ошибке файл просто пропускается
   - Нет докачки частично скачанных файлов

3. seen и visited — дублирующиеся проверки
   - seen проверяется в fetch_one
   - visited проверяется при добавлении в queue
   - Логика избыточна, может привести к пропуску папок

4. Нет пагинации list_dir
   - Лимит 1000, если файлов больше — они теряются
   - Нужна обработка offset

5. Нет прогресс-бара
   - При скачивании сотен файлов не видно прогресса
   - Логируются только начало и конец

6. get_download_link() может упасть без обработки
   - Если API вернёт ошибку, исключение пробрасывается в process()
   - Нет try/except вокруг get_download_link

7. Нет проверки свободного места на диске
   - При скачивании больших файлов может закончиться место

8. Пути с кириллицей в логах
   - При выводе в cmd.exe кириллица ломается (кракозябры)
   - Нужно явно кодировать вывод в UTF-8

9. Ошибки скачивания не повторяются
   - Файл не скачался → записан в errors, но не повторяется
   - Нет финального прохода по ошибкам

10. Нет обработки исключений на уровне файла
    - Если упадёт сеть, asyncio.gather упадёт целиком
    - Нужен индивидуальный try/except для каждого файла
